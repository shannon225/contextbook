EncyclopeDIA changelog for user-facing changes:

encyclopedia-3.0.0-SNAPSHOT
 - Feature: updated scoring system to EncyclopeDIA 2.0 by default
 - Feature: added "-minIntensityNumIons" to filter raw files based on minimum number of ions measured (default is -1 or "off", Thermo raw files only)
 - Feature: added option to specify a new FASTA when combining multiple libraries together. This can be beneficial if libraries were originally created with different FASTA databases
 - Feature: added "-maskBadIntegrations" to suppress background quantification when no "quantitative" ions are found. This inserts 0s for quant, which is useful in testing knockout studies or circumstances where specific peptides should not be found in certain samples (default is false)
 - Feature: added "-integratePrecursors" to use Scribe-like precursor integration for DIA datasets (default is false)
 - Feature: added "-subtractBackground" to background subtract quantitative ions using a moving median (default is true)
 - Feature: added "-adjustInferredRTBoundaries" to allow user to toggle trust of match-between-runs RTs (default is false)
 - Feature: added "-minNumIntegratedRTPoints" to force a minimum number of integrated RT points to define a peak (default is 3)
 - Bugfix: check if any DDA data was searched with Scribe before using min/max with Percolator for Quant Reports
 - Bugfix: fixed error parsing Pecan/Walnut primary score when making chromatogram libraries or Quant Reports
 - Bugfix: fixed error in m/z mass inconsistency between PeptideQuants and Entries tables when using non-chromatogram library searches. This fixes some behavior with Skyline
 - Bugfix: fixed StackOverflowError in mass accuracy calculation when searching very long files with Scribe
 - Bugfix: fixed protein grouping error in parsimony calculation
 - Bugfix: fixed bug specifying Percolator test and train FDRs when using Percolator 3.05 and above (thanks Seth!)
 - Bugfix: fixed minor bugs in parsing Spectronaut Libraries

encyclopedia-2.12.30
 - Feature: added Scribe searching and precursor quant for DDA
 - Feature: updated scoring system to EncyclopeDIA 2.0, default is still 1.0
 - Feature: added spectrum-specific browsing and annotation to peptide browser, added precursor browsing and the ability to export or append spectra to libraries
 - Feature: support for DIA-NN libraries through OpenSwath/Spectronaut parser
 - Feature: added "-mergeLibraries" command line option to merge/RT align across multiple libraries
 - Feature: added drag and drop for combining libraries and GPF-DIA runs. These features now operate within the queue, making it possible to queue up multiple merges
 - Feature: major speedup when preparing quant reports by only giving percolator access to the best scoring targets and decoys
 - Feature: improved/sped up ROC plotting in feature browser
 - Feature: added batch driving multiple searches from the GUI or the CLI using an XML driver file
 - Feature: added automatic iRTDB export along with exports to BLIB
 - Feature: added mass accuracy analysis over retention time for both MS1 and MS2
 - Feature: added option to toggle TIC normalization (default remains on)
 - Feature: added options to generate Prosit libraries for DDA
 - Feature: added checks for Java version to flag Java 17
 - Feature: updated first pass percolator to only perform 3 rounds of optimization to speed up analysis
 - Bugfix: removed Jzy3D from build, which introduced an old version of Log4J
 - Bugfix: changed default behavior of “-quantifyAcrossSamples” to "true" to match GUI. This setting is only used if "-a true". If "true" and "-a true", then for below threshold peptides EncyclopeDIA will search within a +/- 1.5*expectedPeakWidth window around the RT alignment for the best peptide location. If "false" and "-a true", then for below threshold peptides EncyclopeDIA will always integrate entirely based on the exact RT alignment.
 - Bugfix: forced recalculation of precursor m/z in MSP reading to hide a bug in Prosit
 - Bugfix: removed recursive error with long gradients in KDE estimation for RT
 - Bugfix: fixed IO bug if results directory does not exist yet

 - Bugfix: fixed treatment of AMU tolerances in GUI
