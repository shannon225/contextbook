EncyclopeDIA changelog for user-facing changes:

encyclopedia-0.9.6-SNAPSHOT

encyclopedia-0.9.5 (Jun 5, 2020)
 - Feature: support for phospho windowing boundaries in the Window Scheme Wizard
 - Feature: support for Prosit and library conversion tools to the command line (-convert)
 - Feature: added options for passing some training flags to Percolator
 - Feature: added new flags to search for positional isomers and additional PTMs

encyclopedia-0.9.0 (Jun 25, 2019)
 - Feature: added read/write support for Prosit libraries, including making Prosit input from FASTA databases
 - Feature: added ability to preprocess mzMLs into DIAs to speed up searches on servers with slow disk access
 - Bugfix: significantly sped up the Spectronaut library reader

encyclopedia-0.8.2 (May 24, 2019)
 - Feature: added support for converting Spectronaut libraries
 - Feature: added metadata to elib export indicating if RT alignment was performed
 - Feature: added command-line options in Walnut GUI
 - Feature: added ability to clear jobs in GUI
 - Feature: added Maxquant msms.txt parsing to build DDA spectrum libraries
 - Feature: added simplify GUI option to help make figures with the multi-elib browser
 - Bugfix: fixed parsing of MSP files to work with Progenesis
 - Bugfix: updated peptide reversing and randomization to always keep both the n- and c-termini in place. Previously n-termini could be moved
 - Bugfix: fixed bug where the GUI setting for Target/Decoy Approach wasn't correctly setting the numberOfExtraDecoyLibraries flag

encyclopedia-0.8.1 (Jan 14, 2019)
 - Feature: new Window Scheme Wizard for setting up instruments in Help Menu
 - Feature: added ability to change the number of chromatogram columns in the multi-elib browser
 - Feature: added m/z to the table in the multi-elib browser
 - Feature: added ability to ignore current online version
 - Feature: don't need to rebuild library files if they already exist for faster demos
 - Bugfix: patched error when trying to export reports on samples without shared peptides (e.g. chromatogram libraries) in BLIB format
