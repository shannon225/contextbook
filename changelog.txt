EncyclopeDIA changelog for user-facing changes:

encyclopedia-2.0.0-SNAPSHOT
 - Feature: added Scribe searching for DDA
 - Feature: added spectrum-specific browsing and annotation to peptide browser, added precursor browsing and the ability to export or append spectra to libraries
 - Feature: support for DIA-NN libraries through OpenSwath/Spectronaut parser
 - Feature: added "-mergeLibraries" command line option to merge/RT align across multiple libraries
 - Feature: added drag and drop for combining libraries and GPF-DIA runs. These features now operate within the queue, making it possible to queue up multiple merges
 - Feature: major speedup when preparing quant reports by only giving percolator access to the best scoring targets and decoys
 - Feature: improved/sped up ROC plotting in feature browser
 - Feature: added batch driving multiple searches from the GUI or the CLI using an XML driver file
 - Feature: added automatic iRTDB export along with exports to BLIB
 - Bugfix: removed Jzy3D from build, which introduced an old version of Log4J
 - Bugfix: changed default behavior of “-quantifyAcrossSamples” to "true" to match GUI. This setting is only used if "-a true". If "true" and "-a true", then for below threshold peptides EncyclopeDIA will search within a +/- 1.5*expectedPeakWidth window around the RT alignment for the best peptide location. If "false" and "-a true", then for below threshold peptides EncyclopeDIA will always integrate entirely based on the exact RT alignment.

encyclopedia-1.12.31 (December 31, 2021)
 - Feature: removed Log4J dependency from EncyclopeDIA build
 - Feature: updated TraML parsing to significantly improve speed
 - Feature: added official Docker image at DockerHub (searlelab/encyclopedia), thanks Rico!
 - Bugfix: updated Percolator weights file loading to maintain both first pass and second pass Percolator analysis, and always respect the last Percolator model used

encyclopedia-1.11.19 (November 19, 2021)
 - Feature: added saving and loading of Percolator weights files
 - Feature: added "-blibToLib" command line option to convert BLIBs to DLIBs
 - Feature: removed Percolator 3.05 from GUI, but can still specify through additional command line options
 - Feature: added RT alignment when combining multiple libraries
 - Bugfix: fixed integration boundary errors when multiple windows are used to span the peptide at different retention time blocks
 - Bugfix: massive speedup if using .mzML or .DIA files with multiple groups of precursorIsolationWindows (e.g. combined GPF-DIA)
 - Bugfix: update for writing Mac M1 compatible result files (Sqlite update) 
 - Bugfix: enforcement of Prosit limit for charge state between 1 and 6

encyclopedia-1.4.10 (April 10, 2021)
 - Feature: added command-line options to test new pre-release features
 - Feature: added Percolator 3.05, but default is still 3.01 pending additional testing
 - Feature: added mzML preprocessing (including merging gas-phase fractions) to command line
 - Feature: added OpenSwath library conversion to command line (thanks Konstantin)
 - Bugfix: forced adding peptide integrations into elibs even if the peptide is not detected in that sample
 - Bugfix: fixed integration boundaries in elibs even if the peptide is not detected

encyclopedia-1.2.2 (Feb 2, 2021)
 - Feature: added OpenSwath TSV reader
 - Feature: added MS2PIP reader/writer
 - Feature: added "-topNTargetsUsed" option to limit the number of fragment ions used in a library per peptide
 - Feature: added precursor plotting to multi-elib browser as a butterfly plot
 - Feature: added MSP export
 - Bugfix: fixed sorting error causing Percolator irregularities when exporting search results from multiple raw files
 - Bugfix: modified how peak boundary selection works to better respect -expectedPeakWidth
 - Bugfix: fixed integration boundaries to expand beyond -expectedPeakWidth if necessary
 - Bugfix: fixed bug failing to integrate valid peptides due to having multiple repeated entries in the same library in rare cases
 - Bugfix: increased default Percolator training size to 500,000 to improve stability
 - Bugfix: added Percolator additional training fields for +1 and +4 precursors
 - Bugfix: added +3H and +4H fragments for +4H and +5H peptides
 - Bugfix: improved Unimod support for MSP reading
 - Bugfix: fixed treatment of AMU tolerances in GUI

encyclopedia-0.9.6 (Jul 24, 2020)
 - Feature: added ability to create Prosit input files from EncyclopeDIA (DLIB/ELIB) libraries using only the extracted peptides and charge states
 - Bugfix: removed option to demultiplex staggered DIA in the GUI. If you want to use this feature, then use the additional command '-acquisition OVERLAPPINGDIA'. However, we strongly suggest doing this in ProteoWizard instead. 
 - Bugfix: fixed parsing of Inf and NaN values from mass/intensity arrays in mzMLs

encyclopedia-0.9.5 (Jun 5, 2020)
 - Feature: support for phospho windowing boundaries in the Window Scheme Wizard
 - Feature: support for Prosit and library conversion tools to the command line (-convert), thanks Konstantin!
 - Feature: added options for passing some training flags to Percolator
 - Feature: added new flags to search for positional isomers and additional PTMs

encyclopedia-0.9.0 (Jun 25, 2019)
 - Feature: added read/write support for Prosit libraries, including making Prosit input from FASTA databases
 - Feature: added ability to preprocess mzMLs into DIAs to speed up searches on servers with slow disk access
 - Bugfix: significantly sped up the Spectronaut library reader

encyclopedia-0.8.2 (May 24, 2019)
 - Feature: added support for converting Spectronaut libraries
 - Feature: added metadata to elib export indicating if RT alignment was performed
 - Feature: added command-line options in Walnut GUI
 - Feature: added ability to clear jobs in GUI
 - Feature: added Maxquant msms.txt parsing to build DDA spectrum libraries
 - Feature: added simplify GUI option to help make figures with the multi-elib browser
 - Bugfix: fixed parsing of MSP files to work with Progenesis
 - Bugfix: updated peptide reversing and randomization to always keep both the n- and c-termini in place. Previously n-termini could be moved
 - Bugfix: fixed bug where the GUI setting for Target/Decoy Approach wasn't correctly setting the numberOfExtraDecoyLibraries flag

encyclopedia-0.8.1 (Jan 14, 2019)
 - Feature: new Window Scheme Wizard for setting up instruments in Help Menu
 - Feature: added ability to change the number of chromatogram columns in the multi-elib browser
 - Feature: added m/z to the table in the multi-elib browser
 - Feature: added ability to ignore current online version
 - Feature: don't need to rebuild library files if they already exist for faster demos
 - Bugfix: patched error when trying to export reports on samples without shared peptides (e.g. chromatogram libraries) in BLIB format
